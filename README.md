### Hey, I'm Abdullah 👋

_Full Stack .NET Developer · C# · ASP.NET Core · React · Kotlin · KMP_

<br/>

I build **scalable enterprise systems** with **C#**, **ASP.NET Core**, **Entity Framework Core** and **Microservices**, ship web front ends in **React**, and build **Android & Kotlin Multiplatform** apps on top of those APIs.

Over **3.5+ years** I've delivered production software end to end — from **financial trade-settlement platforms** and **government approval workflows** to a **barcode-driven Warehouse Management System** — and deployed it to **Microsoft Azure** with secrets kept in Key Vault.

I care about **clean architecture**, **fast queries**, and code that's **easy to maintain**.
